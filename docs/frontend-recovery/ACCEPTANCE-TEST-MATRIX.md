# 前端恢复验收矩阵（W60 自动化与剩余人工验收）

下列是原始测试清单。W60 已建立隔离 Chromium 自动用例，**只有其对应 Actions 绿色才代表被覆盖场景通过**；纯模拟 API 与真实支付沙箱/生产环境不可混为一谈。推荐在隔离数据库、测试网络或模拟服务商中执行，不得对真实商户进行测试支付或通知。

| ID | 类别 | 测试操作 | 断言 |
|---|---|---|---|
| T01 | 认证 | 未登录访问 /admin/api/v1/orders | 401，不能返回 HTML |

### W60 自动/人工映射

- **浏览器隔离用例（需查 W60 Actions 实际结果）：** T02（前端会话/登录/退出/JWT 失效）、T03（浏览器读取毫秒时间）、T05/T06（模拟选择并核对唯一 POST/子单 UI）、T10（旧目标不覆盖新界面）、T14/T15（已支付需 SQL 确认、超时、GET 错误恢复）、T23（公开 config 敏感字段脱敏）、T25（六语言及宽度截图）、T27（10010 冲突）；Go 路由回归覆盖其余支付契约的部分编码分支。
- **Go 隔离数据库/回归（需查 W60 Actions 实际结果）：** T01（路由 auth 返回 401）、T07/T08/T09/T11/T12/T13/T22/T24/T28/T29 的服务端契约安全分支、W53/54/55 Hash 幂等、父子原子归属、回调租约，并在 MySQL 5.7 两独立连接中验证重复交易 claim。
- **仍需明确人工/沙箱验收：** T04 的真实订单生命周期、T16 商户回跳与 3 秒跳转、T17/T18/T19（W31 暂缓）、T20 导出浏览器下载、T21 钱包批量导入交互、T26 旧 PWA 升级，以及 T23/T24 的真实部署密钥审查；上述不得仅凭 W60 模拟宣称已通过。
- **高风险阻断：** 真实付款、OkPay 官方沙箱下单/回调、第三方商户幂等收件端与多进程重启/断网故障演练不在自动浏览器范围内；详见 [W60-RELEASE-CHECKLIST.md](./W60-RELEASE-CHECKLIST.md)。
